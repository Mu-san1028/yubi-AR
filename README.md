# yubi-AR
カメラに1〜2枚のマーカーを見せて、相手に伝える言葉をつくるARアプリケーション。たとえば、「お願いします」と「待ちます」を表す2枚を同時に見せると、「待ってください」と表示される。
大学の授業で3人チームを組み、UnityとVuforia Engineを使って制作しました。私はマーカー認識の実装、町での会話チャレンジの追加に携わりました。

## ここが面白いぞ！
### 2枚のカードから、新しい言葉ができる
1枚で「はい」や「ありがとう」などの言葉を伝えられます。2枚を組み合わせると、「手伝ってください」や「待ってくれてありがとう」といった文になります。どのカードを組み合わせれば伝えたい文になるかを考え、実際に手を動かして試せるのが面白さです。
### 覚えた組み合わせで、町の住人に返事をする
練習モードでは、お題に合うカードを選び、難しい問題はヒントを見たり後から復習したりできます。「まちで会話チャレンジ」では、住人の言葉に合う返事をカードでつくります。制限時間は90秒。練習で覚えた組み合わせを会話の中で思い出し、時間内にどれだけ返答できるかに挑戦します。

## 工夫したところ
### カードを出し入れする途中で、答えが確定しないようにした
2枚のカードを見せるとき、カメラには片方が先に映ることがあります。また、カードを持ち替える途中で、一瞬だけ認識が途切れることもあります。そこで、同じ組み合わせが一定時間続いてから言葉を確定するようにしました。
練習では、次の問題に進んだあと、一度すべてのカードを隠すと次の回答を受け付けます。これにより、前の問題で見せたカードが、そのまま次の問題の答えとして判定されるのを防いでいます。

### 2枚が一つの文になることを、AR演出で見せた
入力が確定すると、カードの近くに意味に対応したアイコンが現れます。2枚の場合は、それぞれのアイコンが光の線に沿って中央に集まり、組み合わせた文に対応する演出に変わります。文字を読む前にも、どのカードが読み取られ、2枚が一つの入力になったかが分かるようにしました。
